# Source registry

Last reviewed: **2026-07-26**.

This registry records canonical starting points. It is not yet the complete per-set bibliography required by Phase 3.

## Tier 1 — core and rulings

### Current competitive Core Rules

- Title: `Unmatched — Core Rules`
- Publisher host: IELLO
- URL: https://iellogames.com/wp-content/uploads/2024/02/UN-Adventures_Core-rules_EN_Light.pdf
- Role: current general competitive rules; includes two-player rules plus free-for-all/team deltas.
- Status: verified entry point.

### Unmatched Rulings Archive

- URL: https://docs.google.com/document/d/13b-FbPq_vuqcc3IokeHvQ2ctJaDNZZuUaZmt4uft5h0/
- Role: living compilation of publisher/designer rulings and errata.
- Authority note: the Unmatched Reference describes this compilation as considered official by Restoration Games.
- Status: verified entry point; individual rulings still require per-record provenance during extraction.

## Tier 2 — consolidated reference

### Unmatched Reference v10.0

- Version: `10.0 (October 2025)`
- URL: https://how-to-play.s3.us-east-2.amazonaws.com/295564/rules/295564_rules.pdf
- Role: consolidated competitive reference covering official errata, major rulings, character rules, card effects, battlefield effects and set reference through its publication scope.
- Important limitation: the document itself identifies some text as editorial synthesis. Use it to discover mechanics and corrections; confirm sensitive interpretations against official sources/rulings.
- Freshness limitation: later 2026 releases/addenda require separate sources.

## Tier 3 — published fighter/deck database

### UmDb published decks

- URL: https://unmatched.cards/umdb/decks/stats
- Role: normalized index of officially published deck data.
- Useful data: fighter/sidekick stats, movement, special ability, deck counts, card names/users/types/values/BOOST/effects.
- Rule: only `/umdb/...` entries are eligible for the official corpus. `/decks/...` is the fan-deck area.

### UmDb sets

- URL: https://unmatched.cards/umdb/sets
- Role: release/set discovery and cross-checking.

### UmDb battlefields

- URL: https://unmatched.cards/umdb/boards
- Role: battlefield catalog/discovery.
- Limitation: does not replace independent verification of the engine graph (nodes, edges, zones, starting spaces and special connections).
