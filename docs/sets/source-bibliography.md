# Phase 3 source bibliography

**Last reviewed:** 2026-07-26

This bibliography records the source families used to establish the exhaustive release/content registry. Individual records in `registry.yaml` retain their own direct provenance.

## Current official catalog and freshness

### Restoration Games — Unmatched collection

- https://restorationgames.com/unmatched/
- https://restorationgames.com/product-category/games/unmatched-games/
- https://restorationgames.com/product-category/accessories/unmatched-accessories/

Use these to determine the currently advertised games/accessories. They are **not** historically exhaustive because retired licensed products may disappear from the current catalog.

### Published-set count / Vault policy

- https://restorationgames.com/the-unmatched-vault-cobble-fog/

Restoration stated on 2025-11-18 that it had published 24 Unmatched sets with more than 60 fighters, explained the Vault model, and announced the return of Cobble & Fog with small rulebook clarifications. This is used as a high-level completeness checkpoint, not as a substitute for the per-record registry.

### Stars & Stripes release

- Product: https://restorationgames.com/shop/unmatched-stars-and-stripes/
- Release announcement: https://restorationgames.com/press-release-unmatched-stars-and-stripes/
- Rulebook: https://restorationgames.com/wp-content/uploads/2025/08/UM-Stars-Stripes_Rulebook-FLAT.pdf
- Secret Passages addendum: https://restorationgames.com/wp-content/uploads/2026/03/UM-SnS-rules-addendum_color.pdf

The announcement establishes webstore release on 2026-03-16 and full retail release on 2026-06-24. The addendum is a first-class authoritative correction because the White House Secret Passages rules were omitted from the main rulebook.

### Hellboy freshness

- Product placeholder: https://restorationgames.com/shop/unmatched-hellboy/
- Announcement: https://restorationgames.com/gen-con-blueprints-announcement-recap/

The announcement describes a future four-character licensed set. The current product page still exposes no fighter roster/rulebook/playable content. The registry therefore tracks the product but blocks its gameplay corpus.

### Bruce Lee / Muhammad Ali

- Release/design history: https://restorationgames.com/unmatched-the-ultimate-fighters-bruce-lee-vs-muhammad-ali/
- Current product entry is linked from the Restoration Unmatched collection.

The history article is important provenance: Bruce Lee originally shipped as a solo fighter, the license expired, and he later returned in the Bruce Lee vs. Muhammad Ali product. The project therefore models a single canonical Bruce Lee fighter lineage with multiple release memberships/editions rather than silently treating the same fighter identity as unrelated content.

## Secondary completeness indexes

These sources are lower authority under `docs/sources/source-policy.md` but are useful for detecting omissions in retired/historical content.

### BoardGameGeek Unmatched Game System index

https://boardgamegeek.com/wiki/page/thing%3A295564%3Amoreinfo

Useful for historical set order, fighter/sidekick lists, battlefield names and special-component discovery. Any gameplay mechanic discovered here is promoted to canonical behavior only after an official source/ruling supports it.

### UmDb

- Published decks: https://unmatched.cards/umdb/decks/stats
- Sets: https://unmatched.cards/umdb/sets
- Battlefields: https://unmatched.cards/umdb/boards

Only `/umdb/...` is eligible as the published-content index. `/decks/...` is fan content and is excluded.
